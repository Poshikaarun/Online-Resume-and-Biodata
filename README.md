
# Resume & Biodata Website

##  About the Project

A personal **Resume and Biodata Website** created using HTML, CSS, and JavaScript. It presents personal information, education, skills, projects, achievements, and contact details in a simple and professional format.

##  Technologies Used

* HTML5
* CSS3
* JavaScript

##  Features

* Personal profile
* Educational details
* Technical skills
* Projects and achievements
* Contact information
* Responsive and user-friendly design

## Design

The website follows a simple and professional design suitable for presenting academic and professional information. The information is organized into separate sections so that visitors can easily find the required details.
The design can also be customized by modifying the CSS file according to personal preferences.
